# 📈 Baú de Estudos: Fundamentos e Mini Projetos

Bem-vindo ao meu repositório de estudos! Este espaço funciona como um portfólio prático da minha evolução na programação. Aqui, documento meus projetos desde a lógica de programação fundamental até a resolução de problemas reais utilizando **Python** e **C**.

A finalidade deste repositório é construir uma base sólida em Ciência da Computação, explorando estruturas de dados, manipulação de memória, automação e boas práticas de código antes de escalar para sistemas de alta complexidade.

---

## 🛠️ Tecnologias e Conceitos

* **Python 3:** Automação de tarefas, Manipulação de Dicionários, Tratamento de Exceções (`try-except`) e Scripts multiplataforma.
* **C:** Manipulação de ponteiros, alocação de memória, Structs e persistência de dados em disco (File I/O).
* **Git/GitHub:** Versionamento de código, estruturação profissional de diretórios e documentação em Markdown.

---

## ⭐ Projetos em Destaque

*(Navegue pelas pastas do repositório para ver todos os exercícios, ou confira os destaques abaixo)*

* [**🧬 TAD: Lista Genérica (C):**](./C/ListaGenerica) Implementação avançada de uma biblioteca genérica utilizando ponteiros opacos (`void*`) e *Callbacks*. O projeto resolve cenários reais de Infraestrutura, como triagem de chamados de TI e monitoramento de servidores, incluindo ordenação dinâmica e persistência de dados em arquivos `.csv`.
* [**🛒 Mercadinho (Python & C):**](./Python/MercadoNF) Sistema interativo com carrinho dinâmico, cálculo de subtotais e emissão de cupom fiscal em `.txt`. Construído nas duas linguagens para comparar alto e baixo nível.
* [**🚰 Lembrete de Hidratação (Python):**](./Python/Agua) Script de automação rodando em background com notificações nativas do Sistema Operacional.
* [**💬 Chat Local no Terminal (Python):**](./Python/Chat) Simulação de *timeline* de mensagens em tempo real no console utilizando matrizes de dicionários e limpeza de tela multiplataforma.
